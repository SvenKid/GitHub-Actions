# Запуск и сдача задания

Тема: «Вариант А — Автоматизация сборки и тестирования демонстрационного приложения с помощью GitHub Actions».

## Подготовка Windows 10 и IntelliJ IDEA

1. Проверь в терминале `java -version`, `git --version`, `mvn -version`.
   Нужен JDK 17 или новее. Если Maven не установлен отдельно, используй встроенный Maven в IDEA.
2. Клонируй `https://github.com/SvenKid/GitHub-Actions.git` через Git или пункт Clone Repository в IDEA.
3. Открой `pom.xml` как Maven-проект. В Project Structure выбери JDK 17 или новее.
   Для наиболее точного совпадения с CI выбери JDK 17. В настройках Maven Runner проверь JRE.
4. В окне Maven нажми Reload All Maven Projects, затем выполни lifecycle `clean` и `verify`.
5. Убедись, что вывод содержит 6 тестов, 0 ошибок и `BUILD SUCCESS`.
6. В терминале из корня проекта выполни `java -jar target/calculator-1.0.0.jar add 2 3`.
   Результат: `Result: 5.0`. Для дробной части используй точку.

Команды сборки не требуют Node.js, Python, Docker или сервера базы данных.
Первый запуск Maven требует интернета для скачивания зависимостей.

## Если проект получен архивом

Распакуй архив. Для загрузки сначала клонируй существующий репозиторий, затем скопируй в него
содержимое папки проекта из архива, включая `.github` и `.gitignore`. Не копируй `target` и `.idea`.
Проверь изменения и отправь только файлы проекта:

```text
git status
git add README.md pom.xml src .github .gitignore DEMO.md WINDOWS.md
git commit -m "Add Java application and GitHub Actions workflow"
git push origin main
```

Если Git сообщает Author identity unknown, укажи для этого репозитория свои `user.name` и
`user.email`. Не используй чужие данные. При входе в GitHub используй аккаунт с правом записи.

## Что показать преподавателю

- Задача, которую решает GitHub Actions, и публичный репозиторий.
- Настройка workflow с нуля: расположение файла, события, runner, steps.
- Сборка и тесты, запуск JAR и результаты в Actions.
- Намеренная ошибка в вычитании, красный запуск, исправление и зелёный запуск.
- Ответы на вопросы на английском. Сценарий и ответы находятся в DEMO.md.

Само количество тестов и сохранение артефактов — выбранная реализация, а не отдельные
формальные требования преподавателя. Главные обязательные элементы — настройка инструмента,
живая демонстрация на английском и нештатная ситуация.

## Перед сдачей

1. Убедись, что тема GitHub Actions согласована и записана в таблицу потока.
   В предоставленной таблице она не была занята; актуальную запись нужно проверить у преподавателя.
2. Уточни время выступления: в задании есть неоднозначная запись «15–120 минут»,
   а далее отдельно указаны 15 минут демонстрации и 3–5 минут вопросов.
3. В Word-отчёте самостоятельно заполни поля титульного листа по шаблону своей кафедры.
   ФИО намеренно не внесены. Проверь точное название подразделения и данные преподавателя.
4. Разделы 1–3 отчёта должны быть на английском; в приложении должны быть исходники.
5. Убедись, что скриншоты соответствуют реальным запускам именно этого репозитория.
6. Проведи живую демонстрацию без презентации и загрузи Word-файл в DL.

В материалах задания описан первый семестр. Требования других семестров здесь не предполагаются.
